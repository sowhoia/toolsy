# VPN Protector

Мод Toolsy — системный kill switch. Встроенный пакетный фильтр PF выпускает обычный IPv4- и
IPv6-трафик только через VPN-туннель. Если VPN отключится и macOS переключит маршрут на Wi‑Fi или
Ethernet, прямые соединения, включая DNS, останутся заблокированы. Правила работают в ядре и
восстанавливаются при загрузке собственной службой `launchd`; Toolsy для этого не нужен.

Включение, выключение, статус и удаление выполняются с правами администратора через помощник
Toolsy. Проверка конфигурации прав не требует.

## Поля

Списки разделяются запятыми и/или пробелами.

- **Адреса туннеля** — 1–4 локальных IP вашего VPN-интерфейса (видны в клиенте VPN или в
  `ifconfig utunN`). Добавьте IPv6-адрес, если VPN обслуживает IPv6: `198.18.0.1, fd00::2`.
- **Интерфейсы** — необязательные точные имена: `utun4, utun7`. Пусто — подойдёт любой
  `utun0…utun63` с этими адресами. Точные имена заблокируют туннель, если клиент выберет другой номер.
- **Серверы** — 1–8 числовых IPv4-адресов VPN-серверов с протоколом и портом:
  `udp://192.0.2.10:51820, tcp://192.0.2.11:443`. Клиент должен переподключаться по ним без DNS.
  Суффикс `?uid=N` (`udp://192.0.2.10:51820?uid=501`) разрешает соединение с сервером только
  сокетам пользователя с этим UID.
- **Разрешить DHCPv4** — широковещательное получение и продление адреса в сети.

Пока защита включена, поля менять нельзя: выключите её, измените настройки и включите снова.
Включение сохраняет копию `/etc/pf.conf`, применяет правила и сбрасывает состояния PF, поэтому
текущие соединения могут оборваться. При нестандартных правилах PF включение остановится.

## Границы защиты

- Правила защищают от перехода обычного трафика на прямой маршрут после успешного включения. При
  перезагрузке есть интервал до запуска PF. Администратор и системные службы могут изменить его
  конфигурацию.
- VPN-сервер видит исходный IP. Прямой выход разрешён к заданным адресам и портам серверов; с
  `?uid=N` — для сокетов с этим UID, который могут разделять другие приложения того же пользователя.
- Программы могут узнать местоположение другими способами: адреса интерфейсов, геолокация, данные
  аккаунта и Wi‑Fi. Перед работой с чувствительными приложениями проверьте связку VPN, macOS и сети
  на утечки.

Методика проверки на утечки — в [VALIDATION.md](VALIDATION.md). Она написана для консольной версии:
вместо команд `vpn-protector check` и `enable` используйте кнопку «Проверить конфигурацию» и
тумблер мода в Toolsy.

## Если Toolsy недоступен

```sh
sudo /Library/VPNProtector/vpn-protector disable
```

Команда снимает защиту и восстанавливает исходный `/etc/pf.conf` (его копия лежит в
`/Library/VPNProtector/pf.conf.original`). `sudo /Library/VPNProtector/vpn-protector status` покажет
состояние, `… uninstall` после `disable` удалит оставшиеся файлы.

## Сборка

```sh
./build.sh        # build/vpn-protector.toolsymod
swift test        # разбор настроек, правила PF, ответы для Toolsy
```

`scripts/build-mods.sh` в корне репозитория собирает мод и проверяет его валидатором Toolsy
(`toolsy-mod validate`).
