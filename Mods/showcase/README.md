# Витрина

Демонстрационный мод Toolsy: на одной странице собраны все элементы и возможности формата
(`docs/MOD_FORMAT.md`). Он ничего не меняет в системе и не требует прав администратора — только
читает показатели стандартными утилитами macOS (`sysctl`, `netstat`, `ps`, `sw_vers`).

- **Система сейчас** — служба (`scripts/service.sh`) раз в секунду присылает нагрузку, память и
  скорость сети: кольцевые индикаторы, значения с фильтрами `fixed`, `bytes`, `percent`, `rate`,
  график-область.
- **Волна** — линейный график с двумя рядами, полосный индикатор и сохраняемые настройки
  (сегментированный выбор, ползунок, степпер, переключатель). При их изменении Toolsy
  перезапускает службу.
- **Процессы** — команда обновления (`scripts/refresh.sh`, каждые 5 секунд): список с командой по
  нажатию, столбчатый график из массива, выбор-меню.
- **Кнопки и ввод** — поле ввода, обычная, выделенная и разрушительная (с подтверждением) кнопки,
  кнопка-ссылка, команда с ошибкой, трёхсекундная команда, `capture`, «живой» ползунок, `when` и
  `disabled`.
- **Текст и значения** — все стили текста, копируемое значение, фильтр `duration`.

```sh
./test.sh     # запускает каждую команду как Toolsy и проверяет вывод через jq
./build.sh    # build/showcase.toolsymod
```

`scripts/build-mods.sh` в корне репозитория собирает мод и проверяет его валидатором Toolsy
(`toolsy-mod validate`).
